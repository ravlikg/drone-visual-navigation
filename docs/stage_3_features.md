# Етап 3. Виділення ознак і матчинг

Файл: `drone_nav/features.py`

## Що зроблено

* **Детектор/дескриптор:** SIFT (за замовчуванням, `contrastThreshold=0.02`), ORB і
  AKAZE як альтернативи (`--detector`).
* **Ознаки мапи рахуються один раз** і зберігаються в `MapIndex` (≈170 тис. точок, ~3 с).
  Мапа обробляється тайлами 2048 px з перекриттям.
* **Матчинг:** FLANN kd-tree (для SIFT) або BF Hamming (для бінарних), kNN з k=2,
  **ratio test 0.75**, опційний взаємний cross-check.
* **Пошук у вікні:** `MapIndex.window()` повертає тільки точки мапи навколо
  передбаченої позиції, без повторного обчислення ознак.

## Обґрунтування: з лекції

| Що | Слайд |
|---|---|
| 5-кроковий пайплайн, класичні методи | 7 |
| SIFT інваріантний до масштабу й повороту; для дронів це критично (висота → масштаб, курс → поворот) | 10 |
| ORB/AKAZE як швидкі бінарні альтернативи, Hamming | 11 |
| kNN + ratio test 0.7–0.8, FLANN для великої кількості точок | 12 |
| «Start with … SIFT + ratio test: baseline, offline mapping» | 23 |

## Обґрунтування: власне

* **Тайлинг мапи.** Без нього SIFT витрачає точки на найконтрастніші ділянки й
  майже не ставить їх на парки та воду.
* **Знижений `contrastThreshold`**: більше точок на слабкій текстурі.
* **Індекс із просторовим вікном**: швидкий локальний пошук без перерахунку.

## Експеримент: вибір детектора і порогу ratio test

| Конфігурація | Локалізовано /50 | Inliers | RMSE, px |
|---|---|---|---|
| **SIFT, ratio 0.75** | **50** | **290** | **0.30** |
| SIFT, ratio 0.7 | 50 | 284 | 0.29 |
| SIFT, ratio 0.8 | 50 | 296 | 0.31 |
| ORB (auto-scale) | 31 | 32 | 1.02 |
| ORB (scale 1.0) | 29 | 26 | 0.98 |

* Усі три пороги ratio test у діапазоні з лекції дають однаковий результат,
  тож 0,75 обрано як середину.
* **ORB провалює 19 кадрів із 50**, що прямо підтверджує таблицю зі слайду 23
  («ORB … Robustness: Low»): поворот він витримує, а зміну масштабу й
  вигляду між різними знімками погано.
* AKAZE у збірці OpenCV 5 відсутній (винесений з основного модуля), тому в
  таблиці його немає. Код підтримує його в OpenCV 4.x.
